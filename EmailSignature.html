Deployment instructions

Proton Mail:
Settings → All Settings → Account → Identity → Add Signature → toggle to HTML mode → paste the signature table code (everything between the comment markers above).

Outlook (desktop):
File → Options → Mail → Signatures → New → name it "Aubyn" → in the editor click the HTML source button (</>) → paste the table code → Save.
